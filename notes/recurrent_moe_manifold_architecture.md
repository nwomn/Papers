# Recurrent MoE on Neural Manifold: A Brain-Inspired Architecture

> 核心思想：将模型视为大脑结构本身，输入输出对应大脑电信号，在同一神经流形空间中递归运行，通过动态 MoE 路由实现皮层柱式计算。

---

## 0. 想法简述

**一句话**：共享专家池 + 递归迭代 + 自适应终止，在同构的神经流形空间中实现类脑计算。

**核心要素**：
- **I/O 同构**：输入输出在同一空间 M，输出可直接作为下一轮输入
- **共享专家池**：所有层复用同一组专家，不同层通过不同路由选择专家子集
- **动态迭代**：Gate 控制"何时接收新输入"，实现自适应的思考深度
- **神经流形约束**：状态受低维性、平滑性等约束，保证递归稳定性

**训练策略**：
- 阶段一（静态数据）：专家分化 + Gate 学习状态成熟度判断
- 阶段二（交互环境/RL）：路由学习策略性调度 + Gate 适应任务

**生物学对应**：专家池 ≈ 皮层柱基本电路，路由 ≈ 连接模式，Gate ≈ 丘脑门控。

## 1. 核心设计原则

### 1.1 模型 = 大脑结构

模型不是"处理外部数据的工具"，而是大脑本身。模型的输入输出对应大脑中的电信号（神经元群体活动），模型的前向传播对应大脑的一次计算循环。

### 1.2 输入输出同构（I/O Homomorphism）

**输入和输出处于同一空间 M。** 模型的输出可以直接作为下一轮的输入，无需经过编解码转换。

生物学依据：大脑皮层区域之间传递的信号在物理形式上是同质的——都是脉冲序列。V1 → V2 → PFC 的信号编码形式没有本质区别。

这与当前 Transformer 的根本差异：
- 当前模型：输入 = token embedding，输出 = logits/probability，不在同一空间
- 本架构：输入 ∈ M，输出 ∈ M，可直接递归

### 1.3 外界感知注入

每一轮计算中，外界感知信号被编码后注入到模型的内部表示中，类似于感官信号转换为电信号后参与大脑整体计算：

```
y_t = F(Combine(Encode(perception_t), y_{t-1}))
```

这里 `Combine` 的方式可以是加性注入、门控融合、注意力机制等。

### 1.4 动态 MoE 组合（皮层柱结构）

- 每一层都是 Mixture-of-Experts 结构
- **所有层共享同一组专家（same expert pool）**
- 不同层通过不同的路由（routing）选择不同的专家子集

生物学依据：Mountcastle 皮层柱原理——皮层的基本计算单元（皮层柱）在结构上几乎完全相同（六层结构、相似的细胞类型和局部回路），不同皮层区域的功能差异主要来自**输入连接的不同**，而非基本计算电路的不同。

### 1.5 神经流形约束

模型的输入和输出必须满足特定的流形条件，对应真实大脑电信号所满足的神经流形。

生物学依据：虽然大脑有数十亿神经元，但群体神经活动实际上被约束在一个低维流形上。这不是偶然的——它反映了计算的内在结构。

### 1.6 生物学对应关系总结

| 架构组件 | 生物学对应 |
|---------|-----------|
| 共享专家池 | 皮层柱的统一基本电路 |
| 层间不同路由 | 不同皮层区域的不同连接模式 |
| I/O 同构空间 | 皮层间信号的同质性（均为脉冲序列） |
| 神经流形约束 | 神经群体活动的低维流形结构 |
| 低维性约束 | 运动/视觉皮层的 10-30 维有效维度 |
| 平滑性约束 | 突触时间常数、膜电位动力学 |
| 正交性约束 | 不同变量编码于正交子空间（运动方向 vs 速度）|
| 递归处理 | 皮层-丘脑环路的持续循环计算 |
| 外界感知注入 | 感觉传入通路（丘脑中继） |
| Gate 门控函数 | 丘脑门控（控制感觉信号何时进入皮层） |
| 动态时钟比率 | 警觉/专注/沉思等不同意识状态的时间尺度差异 |
| 内部状态变化率 → 门控 | 想法成熟度判断（变化小 = 想明白了 = 接收新输入） |
| 阶段一预训练 | 胚胎期皮层微电路自组织 / 进化形成基本计算单元 |
| 阶段二微调 | 出生后长程连接成熟 + 丘脑门控发育 |
| 自由能最小化 | Friston 主动推断 / 预测编码 |

## 2. 架构总览

```
                    外界感知（视觉、听觉、触觉...）
                            |
                        Encoder
                            |
                        x_ext_t
                            |
                    Combine(x_ext_t, y_{t-1})
                            |
                          x_t ∈ M（神经流形）
                            |
                  ┌─────────┴─────────┐
                  │   Layer 1 (MoE)   │
                  │ [E1, E2, ..., En] │ ← 共享专家池
                  │  Router_1 选择    │
                  └─────────┬─────────┘
                            |
                  ┌─────────┴─────────┐
                  │   Layer 2 (MoE)   │
                  │ [E1, E2, ..., En] │ ← 同一组专家
                  │  Router_2 选择    │ ← 不同的路由决策
                  └─────────┬─────────┘
                            |
                           ...
                            |
                  ┌─────────┴─────────┐
                  │   Layer L (MoE)   │
                  │ [E1, E2, ..., En] │
                  │  Router_L 选择    │
                  └─────────┬─────────┘
                            |
                        y_t ∈ M（同一神经流形）
                            |
                  ┌─────────┴─────────┐
                  |                   |
              输出/动作          y_t → 下一轮输入 y_{t-1}
```

### 形式化描述

```
状态空间:   M（神经流形，紧致低维流形嵌入在高维空间中）
外部输入:   x_ext_t = Encode(perception_t)
状态更新:   y_t = F_θ(Combine(x_ext_t, y_{t-1}))
流形约束:   y_t ∈ M, ∀t
动力系统:   {y_t} 构成 M 上的一条轨迹
```

其中 F_θ 是由 L 层共享专家 MoE 构成的映射：
```
h_0 = Combine(x_ext_t, y_{t-1})
h_l = MoE_l(h_{l-1})    for l = 1, ..., L
y_t = Project_M(h_L)     # 投影回流形 M
```

每层 MoE 共享同一组专家 {E_1, ..., E_n}，但路由函数 Router_l 不同：
```
MoE_l(h) = Σ_i  g_l_i(h) · E_i(h)
```
其中 g_l_i 是第 l 层的门控权重。

## 3. 关键设计细节

### 3.1 同构空间的选择

输入输出空间 M 的选择至关重要。候选方案：

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| 固定维度实向量 + 正则化 | y ∈ R^d + manifold loss | 简单 | 流形约束可能过弱 |
| 超球面 S^{d-1} | 归一化到单位球面 | 自然紧致、防发散 | 拓扑受限 |
| 李群/齐次空间 | 具有群结构的流形 | 有丰富的数学工具 | 实现复杂 |
| 学习的流形（VAE 式） | 通过编解码器隐式定义 | 灵活 | 可能退化 |

### 3.2 流形约束的实施方式：神经科学启发的显式约束

自由能框架提供了隐式流形约束（重构误差），但纯隐式约束在递归迭代中可能不稳定——状态的模数、语义结构容易漂移。因此需要借鉴神经科学中的实证结论，设计显式约束。

#### 神经科学中的神经流形性质

**1. 低维性（Dimensionality）**

实证发现：
- 运动皮层：控制手臂运动的神经活动有效维度只有 ~10-20 维
- 视觉皮层 V1：感知简单刺激时约 10-30 维
- 前额叶：工作记忆任务中约 10-15 维

**2. 平滑性（Smoothness）**

实证发现：
- 神经轨迹在流形上连续且平滑，突变几乎不发生
- 反映神经动力学的内在约束（突触时间常数、膜电位动力学）

**3. 拓扑结构（Topology）**

实证发现：
- 头方向细胞活动形成环面（torus）
- 网格细胞形成六边形晶格
- 拓扑结构与任务/环境相关

**4. 正交性 / 解耦（Orthogonality）**

实证发现：
- 不同任务/变量的编码占据流形的正交子空间
- 例如运动方向和运动速度在运动皮层中编码于正交维度
- 实现信息解耦，便于下游灵活读取

**5. 不变性 / 等变性（Invariance / Equivariance）**

实证发现：
- IT 皮层对物体身份不变于位置、大小、角度
- V1 对方向等变——旋转刺激导致活动模式旋转

#### 综合约束实现

```python
def explicit_manifold_constraints(h, h_prev, semantic_info=None):
    losses = {}

    # === 硬约束（必须满足）===

    # 1. 有界性：防止发散
    losses['bounded'] = F.relu(h.norm(dim=-1) - max_norm).mean()

    # 2. 低维性：通过瓶颈强制
    z = encoder(h)  # 瓶颈维度 d << D
    h_recon = decoder(z)
    losses['reconstruction'] = (h - h_recon).pow(2).mean()

    # === 软约束（正则化）===

    # 3. 时间平滑性
    losses['smoothness'] = (h - h_prev).pow(2).mean()

    # 4. 曲率约束（二阶平滑）
    # 需要 h, h_prev, h_prev_prev
    # acceleration = (h - h_prev) - (h_prev - h_prev_prev)
    # losses['curvature'] = acceleration.pow(2).mean()

    # 5. 有效维度（谱约束）
    if h.shape[0] > 1:  # batch 模式
        cov = torch.cov(h.T)
        eigvals = torch.linalg.eigvalsh(cov)
        eigvals_norm = eigvals / eigvals.sum()
        # 谱熵：太低=坍缩，太高=充满整个空间
        spectral_entropy = -(eigvals_norm * torch.log(eigvals_norm + 1e-8)).sum()
        losses['spectral'] = (spectral_entropy - target_entropy).pow(2)

    # 6. 正交性（如果有语义分组信息）
    if semantic_info is not None:
        # 不同语义子空间之间相关性应该低
        losses['orthogonality'] = compute_orthogonality_loss(h, semantic_info)

    return losses
```

#### 模数稳定性

状态范数/尺度在迭代中漂移是递归系统的常见问题。解决方案：

**方案 A：层归一化**
```python
h = LayerNorm(h)  # 每次迭代后归一化
```
简单有效，但可能丢失模数携带的信息。

**方案 B：软模数约束**
```python
target_norm = running_average(h.norm())  # 历史平均
norm_loss = (h.norm() - target_norm).pow(2)
```
允许模数波动，但不会漂移太远。

**方案 C：能量守恒启发**
```python
energy_t = compute_energy(h_t)
energy_prev = compute_energy(h_prev)
# 能量变化应该有界
energy_loss = F.relu(|energy_t - energy_prev| - delta_max)
```
类比物理系统的能量守恒，提供自然的稳定性保证。

#### 约束分层策略

| 层级 | 约束类型 | 实现方式 | 作用 |
|------|---------|---------|------|
| L0 | 有界性 | 归一化/裁剪 | 防止发散（硬约束）|
| L1 | 低维性 | 瓶颈重构 | 信息压缩（架构约束）|
| L2 | 平滑性 | 时间正则化 | 动力学稳定（软约束）|
| L3 | 谱结构 | 有效维度控制 | 表示质量（软约束）|
| L4 | 语义解耦 | 正交性约束 | 可解释性（可选）|

### 3.3 递归稳定性

作为递归动力系统 y_t = F(y_{t-1}, x_ext_t)，需要避免：
- **坍缩到不动点**：= 停止思考
- **发散**：= 失控
- 目标是工作在**混沌边缘**（edge of chaos）

可能的稳定性机制：
- 流形紧致性本身防止发散
- 噪声注入防止坍缩
- Lyapunov 指数监控/正则化
- 与 Friston 自由能最小化的对接：系统通过最小化自由能维持在吸引子流形上

### 3.4 动态时钟比率：丘脑门控机制

"动态层数"的核心含义不是"自适应计算深度"，而是**模型可以动态控制内部时钟和外部时钟的比率**——即模型自己决定"什么时候再去接收外界输入"。

```
单层模式（实时反应，内:外 = 1:1）：
  外界 → 处理 → 外界 → 处理 → 外界 → 处理

多层模式（深度思考，内:外 = N:1）：
  外界 → 处理 → 处理 → ... → 处理 → 外界 → 处理 → ...

动态模式（自适应，模型自主决定何时接收输入）：
  外界 → 处理 → 外界 → 处理 → 处理 → 处理 → 处理 → 外界 → ...
```

这与 Adaptive Computation Time (ACT) 的本质区别：
- **ACT**：控制输出端——"处理多深再输出"
- **本方案**：控制输入端——"处理多久再接收新输入"

#### 生物学对应：丘脑门控

丘脑（thalamus）不是被动的信号中继站，而是一个**门控系统**，决定哪些感觉信号、在什么时候被放入皮层：
- 警觉状态：丘脑门大开，感觉信号高频涌入 → 单层/少层模式
- 专注思考：丘脑部分关闭，屏蔽无关感觉 → 多层模式
- 深度沉思/做梦：丘脑几乎完全关闭，皮层自己跑内部循环 → 纯内部迭代

#### 形式化描述

```
t_ext = 0                          # 外部时钟
t_int = 0                          # 内部时钟
h = h_init

while running:
    t_int += 1

    # 门控决策：是否接收外界输入？
    gate = Gate(h)                 # 基于当前内部状态决定

    if gate > threshold:
        x_ext = Encode(perception_{t_ext})
        h = Combine(h, x_ext)
        t_ext += 1                 # 外部时钟前进

    # 内部处理（每个内部时钟步都执行）
    h = MoE(h)                     # 共享专家的一次计算

    # h 始终 ∈ M（流形约束）
```

核心是 `Gate(h)` 函数——基于内部状态判断"当前想法是否足够成熟，是否需要新的外部信息"。

#### 门控信号的设计

Gate 可以基于内部状态的**变化率**来判断想法是否成熟：

```
gate = σ(w · ||h_t - h_{t-1}||)
```

- 变化大 → 还在想 → 不接收新输入（gate 关闭）
- 变化小 → 想明白了 → 可以看新东西了（gate 打开）

这实现了"内部表示成熟度"的自动判断。

#### 涌现行为

1. **自动调节反应速度**：危险/突变信号可让 Gate 立即打开（惊吓反射），常规信号下从容思考
2. **时间注意力**：当前注意力机制是空间性的（关注输入的哪些部分），门控是时间性的（什么时候去关注外界），两者结合才是完整的注意力系统
3. **自然的"思考"**：无需额外设计，多层模式本身就是"闭眼思考"

### 3.5 自由能框架：统一的优化目标

#### 从"约束"到"先验"

流形约束可以理解为**先验分布**：不是"必须在流形上"，而是"在流形上的状态先验概率高，偏离流形的状态先验概率低"。

这直接对应 Friston 的自由能原理：

```
F = -E_q[log p(x|h)] + KL[q(h) || p(h)]
  = 预测代价 + 先验代价（流形约束）
```

最小化自由能同时实现：
- **解释观测**：预测准确（预测代价低）
- **符合先验**：状态在流形附近（先验代价低）

#### Gate 与自由能的统一

Gate 决策可以直接基于自由能：

```
F_t 高 → "当前状态不太对" → 打开 Gate，接收新感知
F_t 低 → "当前状态挺好的" → 关闭 Gate，继续内部迭代
```

#### 统一损失函数

```python
def free_energy_loss(h_t, x_ext_t, h_prev):
    # 1. 先验代价：状态离流形有多远？
    #    通过瓶颈重构来隐式计算
    z = manifold_encoder(h_t)          # 投影到低维
    h_reconstructed = manifold_decoder(z)
    prior_cost = ||h_t - h_reconstructed||²

    # 2. 预测代价：状态能多好地预测/解释当前感知？
    x_predicted = predictor(h_t)
    prediction_cost = ||x_ext_t - x_predicted||²

    # 3. 时间平滑性：状态转移应该平滑
    temporal_cost = ||h_t - h_prev||²

    # 总自由能
    F = prior_cost + prediction_cost + λ * temporal_cost
    return F
```

一个损失函数同时实现：流形约束 + 预测准确 + 动力学稳定。

#### MoE 的角色：变分推断

MoE 学习的是**如何从先验（上一状态）和观测（当前感知）推断后验（下一状态）**：

```
专家池 = 一组"推断工具"
单层（gate 打开）：快速结合新感知更新状态
多层（gate 关闭）：在内部空间深度推断，达到更低自由能状态
```

模型自己学会判断"这个情况用哪种策略能最快达到低自由能"。

#### 关于显式流形约束

自由能框架中的 `prior_cost`（重构误差）提供了一种隐式的流形约束。但纯隐式约束可能不够稳定——状态在迭代过程中的模数、语义结构容易跑偏。

因此需要结合神经科学中关于神经流形的实证结论，设计**显式的流形约束**作为补充。这是一个待深入研究的方向（见第 8 节开放问题）。

## 4. 训练策略：两阶段方案

### 核心思路

利用"所有层共享同一组专家"这一架构性质，将训练解耦为两个阶段，对应两种不同的学习范式：

```
阶段 1（静态预训练）：在大规模序列数据集上预训练
    → 专家学习差异化的计算能力
    → Gate 学习"状态成熟度判断"（基于自由能）
    → 计算图浅，标准 BP 即可
    → 类比：皮层柱基本电路的成熟（胚胎发育期）

阶段 2（动态微调）：在交互环境中通过强化学习微调
    → 路由学习策略性的专家调度
    → Gate 微调以适应环境的时间策略
    → 专家权重冻结或极小学习率
    → 类比：长程连接的髓鞘化和修剪（出生后至 ~25 岁）
```

关键洞察：预训练单层 = 预训练所有层的计算单元（因为专家共享），最耗算力的阶段完全避开了深度递归的梯度问题。

### 4.1 阶段 1：静态预训练（序列数据）

#### 目标
1. 训练专家池，使每个专家成为**差异化**的计算单元
2. 训练 Gate，使其学会判断"当前状态是否成熟"

#### 数据要求
**必须是序列数据**，以支持 Gate 的自由能训练：
- 视频帧序列：学习时间连续性
- 文本序列：学习语义预测
- 多模态序列：学习跨模态整合

#### 架构
```
x_t ∈ M → [MoE: Router + {E_1, ..., E_n}] → h
                    ↓
              [迭代若干次]
                    ↓
              Gate 判断是否终止 → 接收 x_{t+1}
```
阶段一可以是单层，也可以是少量固定迭代（2-3次），但不需要完整的动态深度。

#### 专家分化机制（三选一或组合）

**方案 A：随机路由**
```python
# 训练开始时固定分配，每个专家只处理特定输入子集
expert_assignment = hash(input_id) % num_experts
```
简单有效，专家因看到不同数据分布而自然分化。

**方案 B：正交性约束**
```python
# 所有专家参与，但损失函数鼓励输出正交
def orthogonality_loss(expert_outputs):
    # expert_outputs: [num_experts, batch, hidden_dim]
    gram = expert_outputs @ expert_outputs.T
    off_diagonal = gram - torch.diag(gram.diag())
    return off_diagonal.pow(2).mean()
```
不需要预定义分配，通过优化目标驱动分化。

**方案 C：竞争机制**
```python
# Winner-take-all：每个输入只有"赢"的专家得到梯度
outputs = [expert(x) for expert in experts]
scores = [compute_quality(o) for o in outputs]
winner_idx = argmax(scores)
# 只有 winner 参与反向传播
```
强制分化，但训练可能不稳定。

#### Gate 训练（自由能驱动）

Gate 在阶段一就开始训练，学习判断"当前状态能否预测/解释下一时刻的输入"：

```python
for x_t, x_{t+1} in sequential_data:
    h = encode(x_t)

    for iteration in range(max_iter):
        h = MoE(h)

        # 计算自由能：当前状态预测下一输入的能力
        predicted_x = predictor(h)
        free_energy = ||x_{t+1} - predicted_x||²

        gate = gate_network(h)
        if gate > threshold:
            break

    # Gate 训练信号（两种方案）
```

**Gate 训练信号方案 A：自由能阈值**
```python
gate_target = (free_energy < threshold).float()
gate_loss = BCE(gate_output, gate_target)
```

**Gate 训练信号方案 B：效率约束**
```python
# 同时优化预测准确性和迭代效率
loss = prediction_loss + λ * num_iterations
# Gate 通过端到端学习找到平衡点
```

#### 专家位置感知（可选）

**位置无关（默认）**：专家作为纯函数，不知道迭代位置
```python
h = expert(h)
```

**位置相关**：专家接收迭代位置编码
```python
# 加法注入
h = expert(h + iteration_embedding[t])

# 或条件归一化
scale, shift = MLP(iteration_embedding[t])
h = expert(h) * scale + shift
```

#### 其他训练目标（可组合使用）

**去噪自监督**
```
x̃ = Corrupt(x)
Loss = d_M(MoE(x̃), x)
```

**预测编码**
```
Loss = d_M(MoE(x_t), x_{t+1})
```

### 4.2 阶段 2：动态微调（交互环境 / 强化学习）

#### 目标
在专家能力和 Gate 基础判断已建立的基础上，学习：
1. **路由策略**——在动态环境中如何编排专家
2. **Gate 适应**——微调以适应特定任务的时间策略

#### 训练范式
**强化学习 / 交互环境**，而非静态数据集：
- 环境持续提供感知信号
- 模型决定何时接收新输入（Gate）、调用哪些专家（Router）
- 奖励信号来自任务目标

#### 环境选择标准
任务需要体现"思考深度 vs 反应速度"的权衡：
- 实时游戏（Atari）：快速反应 vs 深度规划
- 对话系统：何时需要"想一想"再回复
- 机器人控制：紧急避障（快）vs 路径规划（慢）

#### 参数策略
- **专家权重**：冻结，或极小学习率微调
- **路由参数**：正常学习率，主要学习对象
- **Gate 参数**：正常学习率，从阶段一的基础上微调

#### 课程学习
逐步增加允许的最大内部迭代次数：
```
Phase 2.1：最多 2 次内部迭代
Phase 2.2：最多 4 次
Phase 2.3：最多 8 次
...逐步增加到上限
```

#### 训练信号

| 信号类型 | 大脑对应 | 实现方式 |
|---------|---------|---------|
| 任务奖励 | 多巴胺奖励 | 环境给定的 reward |
| 预测误差 | 预测编码 | 用当前状态预测下一感知，与实际比较 |
| 深度惩罚 | 代谢能耗 | 鼓励用最少迭代完成任务 |

### 4.3 阶段 3（可选）：在线持续学习

部署后的持续适应，对应个体终身学习：
- 专家权重完全冻结
- 仅调整路由权重、Gate 参数和少量适配参数
- 学习信号来自实时的预测误差和环境反馈

### 4.4 三阶段对应关系

| 阶段 | 训练范式 | 学习内容 | 生物学对应 |
|-----|---------|---------|-----------|
| 阶段 1 | 静态数据集（序列） | 专家能力 + Gate 基础判断 | 胚胎期皮层微电路 / 进化 |
| 阶段 2 | 交互环境（RL） | 路由策略 + Gate 适应 | 出生后发育 / 0~25 岁 |
| 阶段 3 | 在线学习 | 环境适应 | 成年后终身学习 |

### 4.5 推理时的弹性计算

```
简单任务（感知识别） → gate 频繁打开 → 快速反应
中等任务（路径规划） → gate 间歇打开 → 适度思考
困难任务（数学推理） → gate 长时间关闭 → 深度思考后再接收新信息
```

这比 LLM 的 Chain-of-Thought 更优雅：CoT 需要生成中间 token 作为思考载体，本架构在表示空间中直接迭代，无需 token 化的中间产物。

### 4.6 Neuroevolution 与 AutoML（可选）

除梯度优化外，本架构的多个组件可通过进化算法和自动机器学习方法搜索/优化：
- **Neuroevolution**：进化搜索专家结构、路由策略、Gate 配置
- **AutoML**：自动调优流形约束权重、训练超参数、实验配置组合

## 5. 与现有工作的关系

| 现有工作 | 相似点 | 本方案的不同 |
|---------|--------|------------|
| Universal Transformer | 共享层参数 | 每层路由不同（MoE），且是递归的 |
| State Space Models (Mamba) | 递归状态更新 | 有显式的流形约束和 MoE |
| Predictive Coding Networks | 预测误差驱动 | 用 MoE 动态选择计算路径 |
| Hawkins' Thousand Brains | 皮层柱理论 | 具体化为 MoE 架构 |
| JEPA (LeCun) | 表示空间预测 | 递归结构和流形约束 |
| Friston Active Inference | 自由能最小化、生成模型 | 具体的 MoE 实现和流形约束 |
| Standard MoE (Mixtral 等) | 专家混合 | 跨层共享专家、递归结构 |

## 6. 开放问题

1. **约束权重调参**：各显式约束（低维性、平滑性、正交性等）的相对权重如何设定？是否需要自适应调整？
2. **流形的数学形式**：是否需要更精确的数学描述（黎曼流形、辛流形）？还是神经科学启发的性质约束已经足够？
3. **时间尺度**：大脑中存在多个时间尺度（快速感知 ~100ms，慢速推理 ~seconds），本架构通过动态时钟比率部分解决，但是否需要多尺度 Gate？
4. **注意力机制的角色**：空间注意力（关注输入的哪些部分）+ 时间注意力（Gate 门控）如何统一？
5. **可扩展性**：这种递归架构在大规模训练中的效率如何？超大专家池的内存和计算管理？
6. **专家容量与数量的平衡**：超大专家池作为"工具池"时，单个专家应该多大？专家数量的上限在哪？

## 7. 实验计划

### 7.1 实验维度与变量

本架构有多个设计维度需要通过实验验证，形成以下实验矩阵：

**维度1：专家分化机制（阶段一）**

| 方案 | 描述 | 实现方式 |
|-----|------|---------|
| 随机路由 | 每个专家被随机分配处理特定输入子集 | `expert_idx = hash(input_id) % num_experts` |
| 正交性约束 | 所有专家参与，损失函数鼓励输出正交 | 最小化专家输出之间的相关性 |
| 竞争机制 | Winner-take-all，只有最优专家获得梯度 | 每个输入只更新"赢"的专家 |

**维度2：专家位置感知**

| 方案 | 描述 | 优点 | 缺点 |
|-----|------|-----|------|
| 位置无关 | 专家不知道自己在第几次迭代 | 简单，专家作为纯函数 | 路由需要学会复杂调度 |
| 位置相关 | 专家接收迭代位置编码 | 同一专家可在不同位置表现不同 | 增加复杂度 |

位置相关的实现方式：
```python
# 加法注入
h = expert(h + iteration_embedding[t])

# 条件归一化（AdaLN 风格）
scale, shift = MLP(iteration_embedding[t])
h = expert(h) * scale + shift
```

**维度3：Gate 训练信号**

| 方案 | 描述 | 实现 |
|-----|------|-----|
| A: 自由能阈值 | Gate 在自由能足够低时打开 | `gate_target = (free_energy < threshold)` |
| B: 效率约束 | 预测准 + 迭代少的联合优化 | `loss = prediction_loss + λ * num_iterations` |

### 7.2 建议的实验顺序

```
第一轮：验证基本可行性
├── 配置：随机路由 + 位置无关 + Gate方案B
├── 目标：确认架构能跑通，专家能分化
└── 观察：迭代次数增加是否带来性能提升

第二轮：对比专家分化机制
├── 固定：位置无关 + Gate方案B
├── 变量：随机路由 vs 正交约束 vs 竞争机制
└── 指标：专家分化程度、最终任务性能

第三轮：对比位置感知
├── 选择第二轮最佳的分化机制
├── 变量：位置无关 vs 位置相关
└── 观察：位置感知是否带来更好的层间协作

第四轮：对比 Gate 训练信号
├── 变量：方案A vs 方案B
└── 观察：哪种信号产生更有效的终止策略
```

### 7.3 验证指标

| 验证点 | 指标 | 期望结果 |
|-------|------|---------|
| 专家分化 | 专家激活模式的余弦相似度 | 低（专家彼此不同） |
| 专家专长 | 不同输入类型的专家激活分布 | 有聚类（某类输入偏好某些专家） |
| 迭代有效性 | 准确率 vs 迭代次数曲线 | 单调递增后饱和 |
| 路由分化 | 不同迭代的路由熵 | 不同迭代的路由模式不同 |
| Gate 有效性 | 不同难度样本的平均迭代次数 | 难样本迭代多，易样本迭代少 |

### 7.4 实验环境选择

**阶段一预训练数据（序列数据）**
- 视频帧序列：学习时间连续性
- 文本序列：学习语义预测
- 多模态序列：学习跨模态整合

**阶段二交互环境（强化学习）**
- 简单：多步算术推理、逻辑推理（bAbI）
- 中等：Atari 游戏（速度-质量权衡）、PathFinder（多步追踪）
- 复杂：机器人控制（紧急避障 vs 路径规划）

关键选择标准：**任务需要多步推理，且存在思考深度与反应速度的权衡**。
